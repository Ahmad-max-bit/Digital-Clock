# Digital Clock

A simple and responsive Digital Clock application built with React and JavaScript.

## 🚀 Features

- Real-time digital clock display
- Modern and clean UI
- Displays hours, minutes, and seconds

## 🛠️ Technologies Used

- *React.js*
- *JavaScript (ES6+)*
- *CSS3*
